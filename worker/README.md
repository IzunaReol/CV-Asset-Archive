# 异步任务服务

当前版本与 API、前端统一为 **2.0.0**。本版模型参数作为 MongoDB 元数据由 API 维护，Worker 不计算指标或连接 MLflow。升级与验证边界见[发布说明](../docs/releases/v2.0.0.md)。

Celery Worker 当前负责：

- SHA-256 校验、图片信息和缩略图；
- 视频基础信息和封面提取；
- 普通标注元数据解析；
- “图片+标注”压缩包识别、导入和关系创建；
- ZIP 导出；
- 回收站后台物理清理。

Worker 与 API 共用 MongoDB、MinIO 和 Redis 配置。Windows 本机环境使用 `--pool=solo`；容器环境使用默认 Worker 启动方式。

任务状态写入 `jobs` 集合，运行期间每 15 秒更新心跳。权限或文件系统错误必须及时把任务和相关素材标记为失败，并保存可展示的中文错误信息。失败任务可通过 API 重新提交；导出任务支持取消；重复导入和关系创建需要保持幂等。
