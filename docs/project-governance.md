# 项目治理约定

## Git 发布授权

任何远程 Git 推送都必须等待项目所有者完成测试，并明确说“可以推送”或给出同等清晰的授权。继续开发、修复问题、UI 评审通过、构建通过、本地提交或提供远程地址均不构成推送授权。

获得授权前可以更新文件、运行测试、整理暂存区和准备提交说明；不得执行 `git push`、创建远程合并请求、创建远程标签或发布 Release。

## 私有输入

`plan.md` 和 `计算机视觉基础设施实施方案.docx` 只作为本地规划来源。两份文件必须保持未跟踪状态并由 `.gitignore` 排除，不得进入公开提交、发布包或示例数据。

## 运行默认值

- 初始管理员用户名和密码均为 `admin`；
- 单文件上传上限为 10 GB；
- 上传上限配置项为 `MAX_UPLOAD_SIZE_BYTES=10737418240`；
- 导出下载默认有效 72 小时。

这些值只用于开发与首次启动。面向团队部署前必须替换默认密码、JWT 密钥和 MinIO 凭据。

## 发布检查

1. 自动化测试、前端构建、Lint 和密钥扫描通过；
2. 项目所有者完成完整手工测试；
3. 全新 Linux 主机可以按文档启动；
4. 备份恢复与升级回滚经过验证；
5. 仓库不包含私有材料、真实数据、运行目录或密钥；
6. README、变更日志、已知限制和版本号一致；
7. 获得明确推送授权。
