# 路线图

## v1.0.0

素材上传、检索、标签、标注预览、关系与模型溯源、回收站、导出和用户管理。

## v1.1.0

数据集成员、不可变版本、版本对比和恢复、复制与导出、模型版本关联、分页与筛选优化。

## v1.2.0

将模型训练关系收敛为已发布数据集版本；当前数据集自动维护图片关联标注。统一数据集筛选与选择流程，完善模型溯源分组、多文件上传并发和相关测试。

## v1.2.1

增加大文件分片续传和服务端选择集，减少批量操作的前端数据量；补充数据集写入恢复、Docker Compose 备份恢复脚本、性能基线脚本以及依赖和容器安全检查。

## v1.3.0

稳定性与任务管理：统一展示素材处理、导出和系统任务，支持类型、状态及创建时间筛选、失败原因、合规重试和导出取消；启动时识别异常中断任务，Worker 定期写入运行心跳。上传支持暂停、继续和分片会话恢复，并增加迁移数据只读核对工具。

## v1.3.1

完成 v1.3.0 全面复核后的稳定性收尾：运行心跳可从临时数据库异常中恢复；上传暂停、默认标签保护和任务操作规则增加前端自动化测试；CI 覆盖全部 Python 脚本并统一 Node.js 版本要求；同步修正文案与验收边界。

## v1.3.2

完成登录会话与生产配置加固：刷新令牌改用 `HttpOnly` Cookie，会话失效后返回登录页并清理缓存；增加生产凭据校验和独立就绪检查；优化任务轮询、手机端任务布局及 Playwright 界面回归测试。

## v1.3.3

收紧大数据量查询边界，数据集选择使用轻量分页接口，溯源图谱限制成员展开数；优化统计聚合和任务索引；增加会话安全解析、登录限流、慢请求日志和覆盖率门槛。

## v1.4.0

- [x] 上传前检查同名同类型文件，并按素材类型分类展示与查看详情。
- [x] 支持覆盖原素材或使用递增文件名上传，后端强制校验冲突处理方式。
- [x] 批量上传取消文件数量限制，覆盖时保留关联关系并增加二次确认。
- [x] 完成上传相关弹窗滚动、夜间主题和确认后操作体验优化。

## v1.5.0

- [x] 过期上传分片由后台定时清理，避免中断上传长期占用对象存储。
- [x] 重名文件检查批量查询素材与关联关系，减少大量文件上传前的数据库往返。
- [x] 数据集“全部”使用服务端选择集，成员列表统一分页加载。
- [x] 关联关系的数据集下拉框支持滚动分页，历史导出文件大小由后台定时补齐。
- [x] 补充关联步骤、任务大小和类型的 UI 回归测试，并提高迁移、管理和对象存储覆盖率。
- [x] 历史版本日期按 2026 年 5 月 15 日至 9 月 27 日均匀整理。

## v1.5.1

- [x] 统一业务弹窗的 Esc、自动聚焦、焦点约束和关闭后焦点归还。
- [x] 关联关系分页改为仅展示当前页附近页码。
- [x] 任务和关系筛选参数使用枚举校验，非法参数返回明确错误。
- [x] 历史导出大小补齐记录成功、失败、最后运行时间和失败日志。
- [x] 后台补齐任务隔离损坏对象，并补充 MongoDB 与 MinIO 恢复测试。

## v1.6.0（2026-10-09）

- [x] 修复 PyJWT 和 urllib3 已知安全漏洞。
- [x] 关系历史改为批量对象查询，数据集版本详情、对比与恢复改为分页或流式批次处理。
- [x] 维护记录与恢复临时备份增加自动过期策略。
- [x] 扩展前端核心工具覆盖率并拆分关系分页、弹窗和数据集版本算法。
- [x] 覆盖上传记录操作历史，素材与关系详情支持上一项、下一项。
- [x] 保存视图支持个人和团队共享范围，批量操作展示逐项结果明细。

## v1.6.1（2026-10-10）

- [x] 增加系统概览、素材占比环形图和按权限返回的全局搜索。
- [x] 增加可复用角色管理、角色权限影响确认和操作入口权限控制。
- [x] 增加上传内容指纹重复检查、异常任务周期恢复和安全事件日志。
- [x] 素材库增加表格列自定义与筛选状态持久化。
- [x] 统一系统日志筛选区和全局下拉框样式。

## 后续

以下为 v2.0.0 之后的工作，不属于本次已完成能力：

- 项目概览合并批量聚合并验证大规模性能。
- 模型选择器改为服务端搜索与分页，避免一次累积加载所有页。
- 增加真实浏览器全链路、全部角色矩阵及页面级测试覆盖。

- Linux全新部署和备份恢复实机演练。
