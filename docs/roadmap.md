# 项目路线图

## M0 仓库、设计与 UI（已完成）

- Apache 2.0 仓库规范、架构、API、运维和治理文档；
- 三套 UI 方向评审；
- 方案 A“数据透镜”评审通过，并吸收方案 C 的夜间配色。

## M1 MVP 归档闭环（功能完成，测试中）

- 登录、RBAC、用户管理；
- 多文件上传、格式识别、媒体预览和处理状态；
- 素材检索、备注、多值标签、高级筛选和保存视图；
- 回收站还原与后台清理；
- 图片与标注自动关联、模型批量关联、历史、撤销和模型溯源；
- YOLO、Pascal VOC、CVAT Images、COCO 导入及矩形框、多边形预览；
- 后台 ZIP 导出和限时下载；
- Windows 本机环境与 Docker Compose。

发布前剩余：用户完整手工验收、10 万条元数据性能基线、备份恢复演练、依赖与镜像安全扫描、全新 Linux 主机部署复现。

## M2 CVAT 在线集成

- 从筛选结果创建 CVAT 任务；
- 同步任务状态并回收标注；
- 建立来源关系、失败重试和人工重新同步。

当前仅支持 CVAT 导出压缩包的离线导入，不包含 CVAT 服务连接。

## M3 MLflow 集成

- 同步 Run、参数、指标和模型；
- 将模型关联到冻结训练集快照；
- 从模型追溯到 Run、数据集版本和成员素材。

## M4 v1.0.0（已发布）

- CI 全部通过且无高危依赖或仓库密钥；
- 文档可在全新主机复现部署；
- 完成已知限制和升级回滚说明；
- v1.0.0 源码、版本标签和 Release 已发布到 GitHub。
