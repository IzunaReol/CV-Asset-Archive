# 路线图

## v1.0.0

素材上传、检索、标签、标注预览、关系与模型溯源、回收站、导出和用户管理。

## v1.1.0

数据集成员、不可变版本、版本对比和恢复、复制与导出、模型版本关联、分页与筛选优化。

## v1.2.0

将模型训练关系收敛为已发布数据集版本；当前数据集自动维护图片关联标注。统一数据集筛选与选择流程，完善模型溯源分组、多文件上传并发和相关测试。

## v1.2.1

增加大文件分片续传和服务端选择集，减少批量操作的前端数据量；补充数据集写入恢复、Docker Compose 备份恢复脚本、性能基线脚本以及依赖和容器安全检查。

## v1.3.0

稳定性与任务管理：统一展示素材处理、导出和系统任务，支持类型、状态及创建时间筛选、失败原因、合规重试和导出取消；启动时识别异常中断任务，Worker 定期写入运行心跳。上传支持暂停、继续和分片会话恢复，并增加迁移数据只读核对工具。

## v1.3.1

完成 v1.3.0 全面复核后的稳定性收尾：运行心跳可从临时数据库异常中恢复；上传暂停、默认标签保护和任务操作规则增加前端自动化测试；CI 覆盖全部 Python 脚本并统一 Node.js 版本要求；同步修正文案与验收边界。

## 后续

- Linux全新部署和备份恢复实机演练。
- CVAT在线任务同步及标注回收。
- MLflow Run、指标和模型登记。
