# UI 评审记录

## 结论

方案 A“数据透镜”已通过用户评审，作为 MVP 界面基线。界面保留高密度素材网格、固定筛选侧栏、批量操作和右侧详情，并加入方案 C 的夜间配色。

当前皮肤名称为“白天模式”和“夜间模式”，通过右上角“界面”选择。两种模式必须覆盖页面、按钮、输入框、日期选择器、弹窗、消息提示和媒体查看器。

## 页面范围

- 概览：系统概览、项目概览；
- 资产管理：素材库、数据集、关联关系、模型溯源、任务中心、回收站；
- 系统管理：标签管理、参数管理、格式管理、用户与角色、系统日志；
- 登录、上传及暂停恢复、素材详情、原分辨率媒体查看、关系选择与预览。

## 交互约定

- 页面标题只显示一个主标题，不重复展示功能说明；
- 页面标题与左侧菜单名称一致；
- 错误提示位于所有弹窗之上，不带成功勾号；
- 详情抽屉切换菜单时自动关闭；
- 所有删除操作先确认，回收站清空在后台执行；
- 独立关系选择器不共享素材库选择状态；
- 文件名和截断字段支持悬停查看全文；
- 图片和视频缩略图可以进入原分辨率查看。
- 无可用操作的任务不显示占位按钮；侧栏显示全部任务数，筛选结果数量显示在页面工具栏。
- 默认标签只显示修改操作，自定义标签允许删除。

后续新增页面应延续以上结构，并使用简洁中文描述功能。

## v2.0.0 交互基线

- 项目概览顶部卡片与下方项目保留间距；单选显示项目名，多选显示数量，窄屏长名称省略并可查看全文；空项目与空模块隐藏。
- 模型展示备注、关联版本和已配置参数，空备注不显示，不展示 MLflow 占位。
- 参数分类默认展开，名称可点击折叠；“分类编辑”集中维护分类，自定义项显示编辑和删除。
- 所有删除确认使用统一危险操作按钮；删除有关联的素材需要再次确认清理关系。
- 素材详情关联数量紧随字段，零值不可点击；历史默认三条，展示全部与收起切换，切换素材时重置。
- 卡片密度按钮只在卡片视图显示，存储空间无有效结果时隐藏区块。
- 数据集详情返回列表后，再次从概览进入列表应显示正确列表；延迟响应不能重新打开已关闭详情或覆盖新素材。

此处记录预期交互，不等同于每项都完成真实浏览器验收；自动化范围见[测试说明](testing.md)。
