# 测试与验收

## 自动化检查

后端：

```powershell
.\.runtime\venv\Scripts\python.exe -m ruff check backend worker
.\.runtime\venv\Scripts\python.exe -m pytest backend/tests -q --cov=app --cov-report=term-missing --cov-fail-under=45
```

前端：

```powershell
cd frontend
npm ci
npm test
npm run test:coverage
npx playwright install chromium
npm run test:ui
npm run build
```

浏览器回归测试会自动启动独立的 Vite 测试服务并模拟 API，覆盖登录强制遮罩、退出后业务缓存清理、手机宽度任务操作可见性、任务大小与类型、关联数据集分页和重置、同名素材分类与详情、弹窗滚动、夜间确认按钮以及确认后上传交互，不读写业务数据库。

隔离 API 流程测试使用独立数据库，覆盖上传、图片标注关联、数据集成员、版本发布、模型版本关系、幂等、图谱、撤销、冲突和类型校验：

```powershell
.\.runtime\venv\Scripts\python.exe scripts/runtime-e2e.py
```

运行前应启动指向独立 `MONGODB_DATABASE`（名称以 `cv_archive_e2e` 开头）的 API 和 Worker，并让 API 监听 8010 端口；脚本会拒绝非隔离环境。测试结束会清理对应数据库与 MinIO 对象。

元数据性能基线可在测试用 MongoDB 上执行 `python scripts/benchmark-assets.py --count 100000`。脚本创建随机命名的隔离数据库、写入合成素材，输出常用查询的 P95，并在结束时删除测试库。不要在承载业务的主机上直接进行 10 万条写入压测。

迁移后数据可使用 `python scripts/verify_migrations.py` 做只读核对。报告检查旧集合对应的数据集、版本和成员差异，不会修改业务数据。

## 手工验收清单

1. 使用六类角色检查页面、接口和越权拒绝，包括自定义角色。
2. 分别验证菜单权限和操作权限：有菜单但无操作权限时可查看但不能修改；无菜单时页面不展示且直接请求读取接口返回 `403 / PERMISSION_DENIED`。
3. 验证自定义角色移除菜单后，该菜单下操作权限同步清除；后端拒绝保存缺少对应菜单的操作权限。
4. 验证登录和恢复会话只加载当前有权限页面的数据，不请求无权限菜单接口。
5. 验证覆盖上传同时要求上传和删除权限，素材及数据集导出同时要求来源菜单和导出权限。
6. 验证旧版 `dataset_manage` 自动迁移为六项数据集细分权限，更新用户后刷新会话被撤销。
7. 上传图片、视频、标注、模型、普通压缩文件与“图片+标注”包。
8. 验证名称和备注模糊搜索、多条件筛选、多值标签、保存视图和分页。
9. 验证图片原图、标注框、视频播放、上一个与下一个媒体切换。
10. 验证 YOLO、VOC、CVAT Images、COCO 的导入、类别名称、矩形框和多边形。
11. 验证自动关联的成功、已有关系、重名冲突和未匹配分类。
12. 验证模型只能关联已发布的数据集版本、不能关联自身或直连素材，重复提交不产生重复有效关系。
13. 验证关系历史、中文来源、可选撤销原因、图谱刷新和撤销详情。
14. 验证删除进入回收站、还原、后台清空状态和对象物理删除。
15. 验证 ZIP 仅包含所选文件、同名处理、任务重试和过期下载。
16. 验证白天与夜间模式、窄窗口、弹窗层级、错误提示和长文件名。
17. 验证图片入集带入标注，解除最后一条图片标注关系后仅调整当前数据集，历史版本和模型图谱保持准确。
18. 验证多文件上传进度和失败提示；大文件上传一部分后重新选择同一文件，确认已完成分片不会重复上传，完成后对象大小正确。
19. 重启全部服务，验证数据、任务状态和预览恢复。
20. 在“全部”模式验证服务端选择集、手动排除、批量标签、删除、集合和导出；确认导出接口拒绝原始数据库查询对象。
21. 在大文件上传过程中执行暂停和继续，确认当前请求停止、继续后复用会话且已完成分片不会重复上传。
22. 验证任务类型、状态及创建时间筛选，失败重试、导出取消、运行心跳和异常中断恢复。
23. 验证默认标签无删除入口且接口拒绝删除，自定义未使用标签可以删除。
24. 上传同名同类型文件时，核对按类型统计结果，并分别验证覆盖原文件和自动重命名上传。
25. 验证全局搜索按分类展示命中总数，并可使用方向键选择、Enter 打开、Esc 关闭；无权限模块不得出现在结果中。
26. 修改已有角色权限，确认保存前准确展示新增与移除权限、正常与停用账号数量以及受影响用户。
