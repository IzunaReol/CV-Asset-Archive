# v2.3.0（候选，2026-11-15）

本版整理 v2.2.1 标签之后尚未提交的改动。当前仅完成发布准备，Git 标签、远程提交和 GitHub Release 均未创建；本地 Docker 与现有服务器此前以 `2.2.1` 镜像标签运行这些功能，不能据此认定它们已运行 `2.3.0` 正式镜像。

## 新增

- 素材库和数据集数据管理支持分别选择当页或全部筛选结果；数据集添加素材弹窗也提供当页／全部，并在高级筛选下提供“应用筛选”。
- 素材添加标签的各入口可从标签值菜单新增唯一值；标签管理在新增、编辑时检查空值、重复值，接口 `POST /api/v1/tag-definitions/{key}/values` 支持并发冲突处理。

## 改动

- 素材库高级筛选默认不带条件，所有条件均可清空。素材库与数据集添加素材的标签字段、标签值改用带颜色、可搜索的自绘菜单；大量标签值只渲染可见项。
- 枚举标签的“包含／不包含”按完整标签值匹配。例如“场景包含出脚”不会命中仅有“未出脚”的素材；备注和手动输入的文本值仍按文字匹配。
- 素材库列表和详情的标签颜色取自标签管理；修复详情标签删除按钮裁剪、无类别名标注的显示及数据管理的标签字号。
- 为素材与数据集 ID、数据集列表排序补齐索引；项目概览停止执行已移除的“其他文件”明细查询。系统概览接口要求对应菜单权限。
- 数据集成员仅查 ID 的接口同时返回类型，支持跨页全选时正确排除标注素材。

## 接口兼容与升级

- `/api/v1` 前缀不变。标签筛选中的 `contains`／`notContains` 对标签字段改为完整值匹配；手动文本输入使用 `textContains`／`textNotContains`。使用旧模糊匹配语义的客户端需调整请求。
- 新索引由 API 启动时创建，首次启动可能短暂增加数据库负载；不迁移或删除现有数据。保留 `.env`、服务器专用 Compose、Caddy 和数据卷，并在升级前备份数据库和部署配置。

## 已完成验证

- 2026-11-15：版本号同步后，后端 305 项、覆盖率 68.80%（门槛 45%）、前端单元 50 项、模拟接口浏览器 81 项、Ruff、前端类型检查与构建通过。前端生产依赖审计为 0 项高危漏洞，95 个本地文档链接有效。按项目声明更新本地 Python 依赖后，`pip-audit` 未发现已知漏洞（自有包由工具跳过）。新增测试覆盖完整标签值匹配、自绘菜单和添加素材筛选。
- 2026-11-14：服务器原有成员统计查询在补齐素材 ID 索引前约 42.5 秒，补齐后约 0.57 秒；当时数据集列表和项目概览接口分别约 640 毫秒、521 毫秒。该结果来自当时约 5,200 条成员关系，不代表更大规模性能保证。
- 最新代码此前已以 `2.2.1` 镜像标签部署到本地 Docker 和现有服务器；本次版本声明改为 `2.3.0` 后尚未重新构建或部署该标签的镜像。
