# v2.0.0（2026-10-22）

本版本汇总 v1.6.1 之后的项目概览、模型参数、素材使用影响、前端重构及缺陷修复。前端、API 和 Worker 版本统一为 2.0.0；接口前缀仍为 `/api/v1`。

## 新增

- 项目概览：按所属项目展示数据集当前素材构成、关联模型和其他文件，支持搜索、单选、多选、全选及清空项目。空项目和无数据区域不展示。
- 数据集必填多选“所属项目”，选项来自标签管理，支持跳转维护项目标签；创建、编辑、复制及接口校验同步更新。不设置数据集“所属算法”字段。
- 参数管理：预置六类共 16 项指标，维护名称、分类、描述；分类编辑弹窗支持新增、编辑和删除自定义分类，默认展开并可收起。
- 每个模型独立配置参数：素材详情“参数配置”和数据集模型管理“编辑参数”共用表单，未配置值显示“未配置”，模型列表及项目概览仅展示已配置值。
- 素材使用影响查询：删除或覆盖前列出关联数据集、历史版本及模型，只展示有引用的素材。
- 全局搜索增加分类总数与键盘选择，扩展文件名、说明、角色及日志字段；角色权限影响预览区分新增、移除权限及正常、停用账号。

## 改动

- 导航分为概览、资产管理、系统管理；系统概览与项目概览归入概览。
- 项目概览顶部对象去重，数据集素材只统计当前成员；同一素材跨数据集使用时，项目成员合计可能重复计数。
- 项目模型包含自身项目标签和项目数据集已发布版本的有效关联两种来源，按模型去重；按项目内关联版本的最新创建时间排序，无关联版本的模型排后。展示备注、版本与参数，不展示 MLflow 占位内容。
- 项目单选显示项目名，长名称省略并保留完整提示；调整卡片间距、窄屏和空区域。其他文件每项目最多预览 50 项。
- 添加模型关联自动带入模型备注，已有关系仅可编辑关联备注；版本单独靠左显示，空备注不显示。
- 关联素材允许删除，需二次确认，并清理成员与关联关系、重算历史版本数量、大小和摘要。回收站还原不会恢复这些关系。覆盖则保留素材 ID 和关系。
- 素材批量标签实时读取管理选项且禁止自定义输入；仅卡片视图显示密度按钮。详情关联数量紧随字段，非零可点击并自动筛选对应素材。
- 操作历史默认三条，可展开及收起；接口支持分页和总数，超过 100 条也可继续读取。
- 修复项目概览进入数据集后返回列表、再从系统概览进入列表的导航状态问题。
- 修复素材切换或关闭后旧响应覆盖详情、标注、历史及备注的问题；修复手机长项目名撑宽页面。
- 模型选择继续加载后续页，不再局限前 200 项；参数保存同步更新时间字段。
- 系统概览素材构成按数量降序、素材占比按实际占比降序；近期操作排除会话失效事件。存储空间不可用时隐藏侧栏区块。
- 前端按业务域拆分页面、状态与共享弹窗，扩大单元和交互测试；统一删除确认样式、分类编辑及折叠交互。
- API 依赖安装成为独立 Docker 构建层；备份结束后只启动原有容器，不隐式构建或拉取镜像。此保证不覆盖恢复备份到全新 Compose 项目的流程。
- Vite 升级至 7.3.7，Vitest 及覆盖率插件升级至 5.0.3；隔离 API 测试补齐数据集所属项目。
- 发布安全检查发现 Pillow 12.3.0 漏洞，Worker 图片处理依赖升级至 13.0.0，并重新执行测试与镜像扫描。

## 升级注意

从 v1.6.1 升级前备份 MongoDB、MinIO 和部署配置，保留旧镜像。启动时补齐预置指标及分类，不覆盖已有配置，无需手工迁移。旧数据集仍可查看，编辑或复制前必须补齐所属项目。

删除关联素材会改变历史版本。回滚镜像不能撤销数据变更，恢复数据需配套备份并在隔离环境验证。见[部署说明](../../deploy/README.md)和[发布检查单](../release-checklist.md)。本次 Git 发布不重新部署 Docker。
