# v2.1.0（2026-10-31）

本版本汇总 v2.0.0 后的改动。前端、API 和 Worker 的产品版本统一为 2.1.0；接口前缀保持 `/api/v1`。Git 标签与 Release 状态以仓库发布页为准。

## 新增

- 数据集发布预检：空集与失效素材阻断发布；无有效标注、重复内容、未划分图片、同内容跨分类及历史一对多标注作为风险提醒。发布人确认提醒后可继续，内容变化会使预检令牌失效。版本记录风险摘要和确认情况。
- 数据集图片分类：在当前数据集内将图片批量设为训练集、验证集、测试集或未划分，支持多选筛选、分类统计与占比。分类是数据集成员属性，不改变素材库的全局标签。
- 自动分配未划分图片：默认比例 8:1:1，可修改非负整数比例；修改后自动更新预览。相同 SHA-256 且大小相同的图片保持同组，已划分同内容图片决定未划分图片的分类；已有分类冲突时跳过并可定位明细。分配尽量接近比例，不保证精确数量。
- 版本发布固定图片分类，恢复版本同时恢复分类，版本对比显示分类变化。旧成员及旧版本图片缺少分类字段时视为未划分。
- 数据管理导出当前所选、全部或指定一个及多个分类。全部导出按 `train/`、`val/`、`test/`、`unassigned/`、`other/` 放置文件；部分导出带上范围内图片的关联标注。任务创建时固定成员、分类与标注归属，ZIP 使用“数据集名称 当前版本 导出类型.zip”，没有已发布版本时用“未发布”。导出内容来自当前建设中的成员，可能与同名已发布版本不同。
- 添加模型关联时可按名称或备注进行服务端搜索和分页；项目概览合并所选项目的文件统计与预览查询。

## 改动

- 新建图片与标注关联时，一份标注最多对应一张图片。已有一对多关系不自动删除；若部分导出会带出其他分类图片的共享标注，则拒绝导出并返回冲突信息。
- 模型参数保存要求提交读取时的修订号，避免覆盖他人更新；已被模型使用的自定义指标必须先清除取值才能删除。
- 系统概览的“最近修改”改为素材分类饼图。数据集分类统计可点击多选，选中后显示重置入口；图片卡片、状态字段、夜间样式和操作按钮间距调整。
- 导出入口移至数据管理；导出弹窗精简说明。自动分配弹窗移除手动预览按钮，比例变化后自动刷新结果，刷新期间禁用确认分配。
- 版本对比等下拉框统一留出文字内边距；清理系统概览、项目概览、任务中心和参数管理标题下方的冗余说明。
- 前端测试依赖 happy-dom 升级至 21.0.4，消除本次本地依赖审计发现的高危告警。
- PyMongo 升级至 4.18.3，并约束 dnspython 与 certifi 的安全版本；发布前本地 Python 依赖审计未发现已知漏洞。
- Linux 首次部署支持预构建镜像包及校验文件；部署前检查配置、镜像、磁盘和端口，启动后核对服务、页面与 API 版本。现场构建方式继续可用。

## 接口与兼容

- 新增发布质量检查、成员分类统计与批量设置、自动分配预览与确认、模型轻量搜索接口。数据集导出扩展 `current`、`all` 和 `categories`，旧调用缺省仍为全部导出。
- 发布请求必须提交质量检查令牌；存在风险提醒时必须显式确认。旧客户端发布版本前需要适配该接口。
- 已有数据集和历史版本不要求立即迁移分类；旧的一对多标注关系保留，但受影响的部分导出可能返回冲突。
- 模型参数 `PATCH` 必须带最新 `revision`；旧客户端需要先读取并提交修订号。
