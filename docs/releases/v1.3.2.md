# v1.3.2

## 版本概述

完成登录会话、生产配置和任务中心的稳定性收尾，并将关键界面流程纳入 Playwright 自动化回归。

## 主要变化

- 刷新令牌仅通过 `HttpOnly` Cookie 传递，前端持久化数据不再保存访问令牌或刷新令牌。
- 页面刷新时会先恢复会话；Cookie 失效或退出后清理业务缓存并返回登录页。
- 生产环境拒绝默认、空值或过短的 JWT、管理员及 MinIO 凭据。
- 就绪探针独立检查 MongoDB、MinIO 和 Redis，单个服务异常不会阻断其他检查。
- 任务轮询根据运行状态调整频率，手机端任务列表优先保留状态和可用操作。
- 增加 Playwright 界面回归测试，覆盖登录层、会话失效和手机端任务操作。

## 升级说明

从 v1.3.1 升级前备份 MongoDB、MinIO 和部署配置。更新代码与依赖，重新构建前端并重启 API、Worker 和前端。升级后需重新登录，以建立新的 `HttpOnly` 刷新 Cookie。

本版本没有数据库迁移。回退时仍应恢复升级前备份，不能只回退代码。

## 验证情况

- 83 项后端测试及 Ruff 全量检查通过。
- 6 项前端单元测试、3 项 Playwright 界面测试、类型检查和生产构建通过。
- 前端生产依赖安全审计通过。
- 版本号一致性、文档链接和发布格式完成复核。

## 已知限制

- Linux Docker 全新部署和容器备份恢复按用户要求跳过，未计入本版本验收。

- 当服务器不可达时，前端会结束本地会话，服务恢复后需重新登录。
