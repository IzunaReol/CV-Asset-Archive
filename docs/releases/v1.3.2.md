# v1.3.2（2026-08-13）

## 新增

- 增加 Playwright 界面回归测试，覆盖登录层、会话失效和手机端任务操作。
- 就绪探针独立检查 MongoDB、MinIO 和 Redis。

## 改动

- 刷新令牌仅通过 `HttpOnly` Cookie 传递，前端持久化数据不再保存访问令牌或刷新令牌。
- 页面刷新时先恢复会话；Cookie 失效或退出后清理业务缓存并返回登录页。
- 生产环境拒绝默认、空值或过短的 JWT、管理员及 MinIO 凭据。
- 单个依赖服务异常不再阻断其他就绪检查。
- 任务轮询根据运行状态调整频率，手机端任务列表优先保留状态和可用操作。
