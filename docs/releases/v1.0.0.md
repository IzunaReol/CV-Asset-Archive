# v1.0.0

## 版本概述

首个正式版本，提供视觉素材归档、检索、预览、关系管理、导出和基础系统管理能力。

## 主要变化

- 支持图片、视频、标注、模型和压缩文件上传与格式识别。
- 支持素材预览、原分辨率查看、标注叠加、高级筛选、保存视图和多值标签。
- 支持 YOLO、Pascal VOC、CVAT Images 和 COCO 标注包导入。
- 支持图片与标注关联、模型关系、关系历史、模型溯源、回收站和异步 ZIP 导出。
- 提供用户、角色、标签、格式、审计、Windows 本机环境和 Docker Compose 配置。

## 升级说明

这是首个正式版本，无历史版本升级步骤。首次部署后应立即修改管理员密码、MinIO 凭据和 JWT 密钥。

## 验证情况

- 完成核心上传、检索、预览、关系、回收站和导出流程验证。
- 完成 Windows 本机环境及基础 Docker Compose 配置检查。

## 已知限制

- 上传采用整文件传输，不支持分片、暂停或断点续传。
- 数据集版本、服务端选择集、任务统一管理、CVAT 在线同步和 MLflow 集成尚未提供。
- 本说明记录 v1.0.0 发布时状态；当前版本能力以最新发布说明为准。
