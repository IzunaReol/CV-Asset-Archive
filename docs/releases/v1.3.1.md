# v1.3.1

## 版本概述

完成 v1.3.0 全面复核后的稳定性、自动化测试和文档一致性收尾。

## 主要变化

- Worker 心跳写入遇到临时数据库异常时不会退出，会在下一周期继续尝试。
- 为上传暂停恢复、默认标签删除保护和任务操作按钮规则增加前端单元测试，并纳入 CI。
- Ruff 检查扩展到全部后端、Worker 和脚本，避免新增校验脚本遗漏静态检查。
- Node.js 最低版本统一为 22.20，并在本机安装脚本中执行版本校验。
- 当前任务通知统一使用“任务中心”，发布文档明确区分版本验收和完整生产部署验收。

## 升级说明

从 v1.3.0 升级前备份 MongoDB、MinIO 和部署配置。更新代码及依赖，重新构建前端并重启 API、Worker 和前端。前端构建环境需使用 Node.js 22.20 或更高版本。升级后应检查运行中任务心跳、上传暂停恢复、默认标签保护和任务中心操作。

回退时应恢复升级前数据库备份，不能只回退代码。

## 验证情况

- 75 项后端测试及 Ruff 全量检查通过。
- 前端单元测试、类型检查、生产构建和生产依赖安全审计通过。
- PowerShell 安装脚本语法、版本号一致性和文档链接检查通过。
- GitHub CI 状态以本版本发布页面显示结果为准。
