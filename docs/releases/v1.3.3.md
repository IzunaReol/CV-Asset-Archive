# v1.3.3

## 版本概述

收紧大数据量查询边界，优化素材与任务查询，并补齐登录防护、可观测性和自动化覆盖率门槛。

## 主要变化

- 数据集列表不再接受 `page_size=0`，关系选择器使用最多 200 项的轻量分页接口。
- 模型溯源图谱最多展开 500 项版本成员，返回完整数量和截断状态，避免一次返回超大图谱。
- 素材统计改为单次 MongoDB 聚合，任务列表增加复合索引。
- 损坏或旧版本会话缓存会自动清理，连续切换素材筛选时只接受最新结果。
- 登录失败按 IP 和用户名组合限流，默认 5 分钟内最多 5 次。
- API 日志改为 JSON 结构，超过阈值的慢请求使用警告级别记录。
- CI 增加后端整体和前端核心策略覆盖率门槛；统一后端测试导入路径，避免同一模块被重复加载后造成覆盖率漏记。

## 升级说明

从 v1.3.2 升级前备份 MongoDB、MinIO 和部署配置。更新依赖、重新构建前端并重启 API 和 Worker。API 启动时会自动创建新的任务查询索引，无需手工数据迁移。

可通过 `LOGIN_MAX_FAILURES`、`LOGIN_FAILURE_WINDOW_SECONDS` 和 `SLOW_REQUEST_MS` 调整登录限流和慢请求阈值。

## 验证情况

- 107 项后端测试、Ruff 和 45% 后端整体覆盖率门槛通过；本机后端整体覆盖率为 49%。
- 标注解析、关系接口和素材接口覆盖率分别提升到 81%、25% 和 37%。
- 7 项前端单元测试、核心策略覆盖率门槛、3 项 Playwright 界面测试、类型检查和生产构建通过。
- 版本号一致性、文档链接和差异格式完成复核。

## 已知限制

- 溯源图谱只展示前 500 项版本成员，完整内容需在数据集成员列表中分页查看。
- Playwright 界面测试仍使用模拟 API，真实 API 浏览器冒烟验收仍使用隔离环境手工执行。
- Linux Docker 全新部署和容器备份恢复按用户要求跳过，未计入本版本验收。
- CVAT 在线任务同步和 MLflow 集成尚未实现。
