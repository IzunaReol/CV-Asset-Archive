# v1.4.0（2026-09-12）

## 新增

- 上传文件前按文件名和素材类型检查当前素材库中的重名文件。
- 重名结果按图片、视频、标注、模型、压缩文件、图片加标注及其他类型分类展示。
- 冲突提示提供“覆盖原文件”和“重命名并上传”两种处理方式。
- 上传按钮上方显示“共 X 项文件”。
- 存在有效关联关系的同名素材在覆盖前增加二次确认。
- 增加 Windows 一键部署和一键启动入口。
- 增加 Linux 一键部署和一键启动入口。
- 首次部署自动生成 JWT、管理员密码和 MinIO 凭据。

## 改动

- 重名分类默认收起，展开后可查看具体文件和素材详情。
- 批量上传不限制文件总数，由前端分批创建和完成上传会话。
- “覆盖原文件”保留原素材 ID、关系、备注和历史数据集引用，只更新当前文件内容。
- 覆盖处理成功后清理已无其他素材引用的旧对象；仍被其他素材共享的对象继续保留。
- “重命名并上传”自动生成递增的文件名后缀。
- 后端上传会话再次校验冲突处理方式，未选择时拒绝创建同名上传任务。
- 上传大小提示读取实际配置，不再写死默认的 10 GB 上限。
- 上传、确认及详情弹窗使用独立滚动区域并锁定背景滚动。
- 覆盖确认按钮统一尺寸并适配夜间主题，确认后上传继续执行且支持暂停。
- 已有部署配置会被保留，仅替换缺失或明显不安全的默认凭据。
- Windows 日常启动不再重复构建镜像；Docker Desktop 未运行时自动尝试启动。
- Linux 部署限制 `.env` 仅当前用户可读写，日常启动复用已有镜像。
- CI 增加 Windows、Ubuntu 部署脚本语法、凭据生成和配置保留检查。
- 所有历史版本说明统一为“新增”和“改动”格式。
