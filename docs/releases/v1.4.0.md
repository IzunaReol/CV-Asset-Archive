# v1.4.0

## 版本概述

优化素材上传的同名文件处理，上传前明确展示冲突范围，并由用户选择覆盖或重命名。

## 主要变化

- 上传文件前按文件名和素材类型检查当前素材库中的重名文件。
- 重名结果按图片、视频、标注、模型、压缩文件、图片加标注及其他类型分类展示；分类默认收起，点击后展开具体文件，再点击素材可在右侧查看详情。
- 冲突提示统一显示“存在共 X 项重名文件，请选择：”。
- 上传按钮上方显示“共 X 项文件”，批量上传不限制文件总数，由前端分批创建和完成上传会话。
- “覆盖原文件”保留原素材 ID、关系、备注和历史数据集引用，只更新当前文件内容；存在有效关联关系时先进行二次确认，确认层关闭后上传继续执行且支持暂停。
- 覆盖处理成功后清理已无其他素材引用的旧对象；仍被其他素材共享的对象继续保留，清理异常不影响已完成的素材处理。
- “重命名并上传”自动生成“文件名 (1).扩展名”，已有同名时继续递增。
- 后端上传会话再次校验处理方式，未选择时拒绝创建同名上传任务。
- 上传大小提示读取实际配置，不再写死默认的 10 GB 上限。
- 上传、确认及详情弹窗使用独立滚动区域并锁定背景滚动；覆盖确认按钮统一尺寸并适配夜间主题。

## 升级说明

从 v1.3.3 升级前备份 MongoDB、MinIO 和部署配置。更新代码、重新构建前端并重启 API 和 Worker。本版本不需要数据迁移。

## 验证情况

- 117 项后端测试、Ruff 和 45% 后端整体覆盖率门槛通过，本机整体覆盖率为 50.67%。
- 7 项前端单元测试、核心策略覆盖率门槛、4 项 Playwright 界面测试、类型检查和生产构建通过。
- 重名分类默认收起与详情、159 项请求校验、未选择处理方式时拒绝上传、递增重命名、关系保留确认、确认后上传可操作、覆盖目标保留和旧对象安全清理完成自动化验证。
- 隔离 API 全流程通过：6 次上传、2 次批量上传、2 项数据集版本成员、1 组自动匹配、1 组重名冲突、1 条模型图谱边，并验证撤销后图谱清理和关系类型拒绝。

## 已知限制

- 同名判断范围为相同文件名和相同素材类型，文件名忽略大小写。
- Linux Docker 全新部署和容器备份恢复按用户要求跳过，不计入本版本验收。
