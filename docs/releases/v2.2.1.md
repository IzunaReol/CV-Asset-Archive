# v2.2.1（2026-11-09）

本次包含 v2.2.0 的前端样式修复，以及同版本后续补丁。数据集新建、编辑弹窗中的“分类规则”下拉框，以及其他业务弹窗中的输入值和下拉选项，统一为 14px。字段标签与辅助说明保留原有文字层级。

自定义标签的内部标识由系统生成，用户填写的“备注”作为独立字段保存、读取和编辑，避免中文备注被当作内部标识提交而报错。前端同步校验用户名、标签颜色、数据集版本号等输入格式，并把常见接口校验错误转为中文字段提示。标签定义新增可选 `remark` 字段；旧调用无需提供，接口前缀保持 `/api/v1`。

前端、API、Worker 版本声明和 Docker 镜像标签仍为 `2.2.1`。已有 `v2.2.1` Git 标签保留原指向；本次补丁作为后续提交进入 `main`，不创建新标签或 GitHub Release。

## 验证

- 本地后端 263 项、前端单元 48 项、模拟接口浏览器 54 项通过；新增浏览器断言核对数据集新建／编辑、参数分类和指标弹窗中的字段字号。
- 后端 Ruff、前端类型检查和生产构建通过。
- 2026-11-11 补丁回归：后端 265 项（覆盖率 68.73%）、前端单元 50 项、模拟接口浏览器 56 项通过；Ruff 和前端构建通过。隔离真实 API 流程覆盖上传、成员与版本、模型关联、标签备注往返及字段校验；隔离测试库和对象桶已清理。
- 本地 Docker 和现有 Ubuntu 服务器的实际部署结果见 [发布检查单](../release-checklist.md)。模拟接口浏览器测试不等于真实服务全链路验收。

## 升级

先保留 `.env`、服务器专用 Compose 配置、Caddy 和数据卷，备份 MongoDB、MinIO 与配置，并保留旧应用镜像。更新应用镜像后仅重建 API、Worker 和前端容器；无需数据迁移。此前版本的功能范围与限制见 [v2.2.0 发布说明](v2.2.0.md)。
