# v1.2.0

## 版本概述

统一数据集、标注和模型关系，模型训练来源收敛为已发布的数据集版本。

## 主要变化

- 模型改为关联已发布的数据集版本，不再新增模型与单个素材的直连关系。
- 图片加入或移出数据集时，同步维护当前数据集内关联标注；已发布版本保持不变。
- 模型溯源展示版本中的图片、标注、视频及其他素材，并标明来源数据集和版本。
- 统一数据集素材选择、筛选和分页，提高多文件上传并发并显示处理进度。
- YOLO 标注缺少类别名称时显示“未命名类别”。

## 升级说明

升级前备份 MongoDB、MinIO 和部署配置。旧模型直连素材关系不会自动转换为数据集版本关系，应先按仓库清理工具生成报告，再使用明确数量和仓库外备份执行清理。更新依赖并重新构建前端后，验证标注预览、数据集版本、模型溯源、导出和回收站。

回退已清理关系时必须恢复升级前数据库备份。

## 验证情况

- 54 项后端测试、Ruff、前端构建和隔离数据库接口测试通过。
- 使用现有模型核对 159 张图片、100 个标注文件、类型筛选和来源版本显示。

## 已知限制

- 上传不支持分片、暂停或断点续传。
- 素材“全部”选择仍由前端分批读取，未完成大规模性能验收。
- 强制退出后的数据集写入恢复仍需完善。
- 本说明记录 v1.2.0 发布时状态；当前版本能力以最新发布说明为准。
