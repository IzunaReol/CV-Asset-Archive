# v1.6.0（2026-10-09）

## 新增

- 数据集版本恢复增加临时备份集合，分批恢复失败时自动回滚原成员，备份在一天后自动清理。
- 增加弹窗辅助逻辑、关系分页和大型数据集版本处理的自动化测试。
- 覆盖上传增加素材操作历史，记录文件名、大小、对象位置和关联关系保留情况。
- 素材详情和关联关系详情增加上一项、下一项操作。
- 保存视图增加共享范围，可选择仅自己可见或团队成员可见。
- 批量上传、标签、删除和恢复增加结果明细，分别展示成功项与失败项。
- 用户管理增加可复制的权限模板，个人菜单增加“我的权限”摘要。
- 用户自定义权限配置增加菜单权限和操作权限的全选、取消选择。
- 系统管理增加“系统日志”页面，支持按关键字、操作、对象类型和创建时间筛选，并可在右侧详情中查看中文变更内容。

## 改动

- 权限模型拆分为菜单访问权限与操作权限；自定义角色可分别配置，固定角色使用统一预设。
- 素材、数据集、关联关系、任务、回收站、标签、格式和用户接口增加后端权限校验，界面同步隐藏无权限操作入口。
- 登录与会话恢复改为按当前页面加载数据，不再预取无权限菜单内容。
- 数据集管理拆分为创建编辑、成员管理、版本发布、版本恢复、删除和模型关联权限；保存视图使用独立权限。
- 覆盖上传同时校验上传和删除权限，素材及数据集导出同时校验来源菜单和导出权限。
- 用户权限更新后撤销该用户的刷新会话，旧版数据集管理权限自动兼容到细分权限。
- 系统日志使用独立菜单权限，管理员默认可见，自定义角色可单独授权。
- 系统日志列表改为显示“类型：目标名称”，不再直接展示对象 ID；请求 ID 后增加详情入口。
- 系统日志中的文件大小统一转换为易读单位，修复包含大小字段时页面渲染为空白的问题。

- 上传完成任务使用固定 ID 并先持久化；投递中断后由后台自动补发，重复消息不会再次处理同一素材。
- 素材删除、回收站还原与清空、数据集删除和覆盖上传收紧为管理员或数据管理员权限。
- 素材库计数按当前筛选结果展示“当前页”和“全部”数量。
- 上传地址生成失败时不再写入上传会话，避免创建任务失败后遗留无效记录。
- 大批量上传改为前端每 25 项提交、后端每 12 项窗口执行，降低大量文件同时上传时的内存占用。
- 修复 Docker 环境创建上传任务时公开 MinIO 地址被 API 容器错误用于区域查询的问题。
- 上传素材弹窗分行说明 10 GB 上限、压缩文件保存方式和 CVAT 数据集包解析方式。
- PyJWT 升级至 2.15.1，urllib3 升级至 2.8.0，依赖安全扫描不再报告已知漏洞。
- PyMongo 升级至 4.18.2，修复依赖安全扫描发现的已知漏洞。
- Vue 升级至 3.5.43，并将 `source-map-js` 固定为 1.2.2，前端依赖审计不再报告已知漏洞。
- Windows 和 Linux 启动脚本检测到 MongoDB 健康检查异常时，会保留数据卷并自动重新创建容器。
- 关系历史列表批量查询源对象和目标对象，不再为每条关系分别访问数据库。
- 数据集版本详情改为分页加载，版本对比改为流式统计全部成员，明细最多展示前 1000 项。
- 数据集恢复按批次校验和写入，避免将目标版本及原数据集成员全部载入应用内存。
- 历史导出大小补齐运行记录增加 90 天自动过期策略。
- 弹窗键盘逻辑、关系分页和数据集版本算法拆分为独立模块，降低大型组件和路由文件的维护成本。
- 批量接口统一返回成功数、失败数和逐项结果，明细过多时明确标记截断状态。
