# v1.5.1（2026-09-29）

## 新增

- 所有可关闭业务弹窗支持 Esc 关闭、打开后自动聚焦、Tab 键焦点约束，并在关闭后将焦点返回原来的按钮或素材。
- 历史导出大小补齐增加运行记录，包含处理数量、成功数量、失败数量、最后运行时间和失败日志，并提供管理员查询接口。
- 增加 MongoDB、MinIO 短暂不可用后的恢复测试，以及损坏对象不阻塞同批任务的隔离测试。

## 改动

- 关联关系分页仅展示首页、末页和当前页附近页码，数据量较大时不再生成大量分页按钮。
- 任务类型、任务状态、关系类型和关系状态筛选改为明确枚举，非法参数返回清晰的校验错误。
- 历史导出大小补齐改为优先处理最久未检查的记录，失败对象会保留错误信息并在后续周期继续尝试。
- 统一业务弹窗语义、长名称换行、窄窗口布局、白天与夜间主题，以及空状态、加载状态和失败状态样式。
