# v2.2.0（发布候选，待发布）

本版本整理 v2.1.0 Git 标签之后的改动。前端、API、Worker 的版本统一为 2.2.0；接口前缀保持 `/api/v1`。Git 提交、标签及 Release 状态以[发布检查单](../release-checklist.md)为准。本地 Docker 已更新为 `2.2.0` 候选镜像，复用现有 2.1.0 依赖层构建；全新镜像构建与 Linux 部署仍须验证。

## 新增

- 数据集新增三种分类规则：标准保留训练集、验证集、测试集；自定义可新增、改名、删除分类，并按各分类比例自动分配未划分图片；不分类隐藏分类操作。旧数据集默认使用标准规则。切换规则会将当前图片分类重置为未划分并清空自定义分类，发布过的版本快照不变。
- 素材库导出可选“导出关联标注”，按所选图片的有效关系固定要导出的标注；已直接选中的标注仍按所选素材导出。数据集当前、全部、指定分类导出也提供“导出关联标注”勾选项，默认不勾选。
- 模型上传格式增加 `.caffemodel`、`.solverstate`、`.mdl`。默认标签增加“数据来源”：开源数据、生产数据、客户反馈数据、AIGC数据、研发数据。
- 参数管理的分类编辑支持上移、下移、置顶；分类顺序应用于指标列表和模型参数展示，调整操作写入审计。

## 改动与修复

- 数据集“导出当前”和“导出全部”直接把文件放在 ZIP 根目录；“导出指定分类”按分类名称建立文件夹，将图片和所选关联标注放在所属分类。文件夹名中不适合路径的字符替换为下划线，重名时追加序号。历史一对多标注若关联导出范围外或多个所选分类的图片，受影响的分类导出返回冲突，不复制标注。
- 模型框架默认值改为 Caffe、Darknet、PyTorch、TensorFlow、PaddlePaddle、ONNX Runtime、TensorRT、OpenVINO。迁移会移除旧预置 YOLO11、YOLOv8、RT-DETR，并保留其他用户自定义值。
- 素材库卡片、表格和详情中的标签按标签管理颜色显示；素材库导出弹窗展示关联标注数量。
- 自动关联结果按数据集聚合当前成员变化，避免相同数据集重复列出。
- 项目概览移除其他文件区域；系统概览素材构成隐藏数量为零的类别，近期操作长字段省略并统一显示中文操作名。
- 前端 Nginx 代理在 API 容器重建时动态解析地址，修复登录请求指向旧地址造成的 502。
- Docker 构建上下文排除本地 Python `egg-info`，避免旧包元数据进入候选镜像并干扰运行时版本查询。

## 接口与兼容

- 数据集创建和编辑增加 `classification_rule`；自定义分类新增创建、改名、删除接口。分类统计、批量设置、自动分配和导出接受当前数据集的分类 ID；旧调用默认标准规则和不导出关联标注。
- `POST /exports/annotation-preview` 返回素材库导出所选图片的有效关联标注数量；`POST /exports` 增加 `include_annotations`。`POST /datasets/{id}/export` 也增加 `include_annotations`，并在创建任务时固定成员、分类与标注归属。
- `PATCH /metric-categories/{id}/move` 接受 `up`、`down`、`top`；分类顺序影响全系统指标展示。
- 数据迁移 006 更新已有库的模型扩展名和模型框架预置值；新“数据来源”标签通过默认标签初始化补齐。升级前应备份 MongoDB、MinIO 和部署配置，并保留旧镜像。
