# v1.1.0

本版本增加数据集与版本管理，并优化模型关联、筛选、分页和批量操作。

## 新增与调整

- 数据集新建、编辑、删除、复制；复制可选择是否包含成员，并填写名称。
- 数据管理支持分页、高级筛选、全选、反选与跨页保留选择。
- 发布不可变版本，自定义版本号，查看历史成员、版本差异及恢复成员。
- 模型关联指定数据集版本，记录备注并管理对应素材关系。
- 素材详情显示所属数据集，点击进入数据管理。
- 数据集导出进入下载中心；标签分布统计全部成员。
- 删除数据集同时清除版本及模型关系，素材文件保留。
- 统一复制弹窗、时间筛选、选择控件和批量失败提示。

## 升级

1. 备份 MongoDB 和 MinIO，停止 API、worker 和前端。
2. 更新到 v1.1.0，安装后端与worker依赖，在 frontend 执行 npm ci 与 npm run build。
3. 启动服务；集合数据自动迁移为数据集，历史冻结集合迁移为首个版本。
4. 验证登录、素材预览、数据集成员、历史版本与模型关联。

Docker Compose 用户更新代码后重新构建并启动容器。回退前恢复升级前 MongoDB 备份，不应仅回退代码。

## 验证

- 前端类型检查和生产构建通过。
- 后端49项测试通过，包含删除清理、恢复失败回滚及锁释放。
- 临时数据集验证了复制、分页、发布、移除、版本对比、恢复及删除。
- 已验证相关页面筛选、版本详情、选择工具和夜间模式控件。

## 已知限制

- 整文件上传暂不支持分片、暂停、断点续传和刷新恢复。
- 全部数据仍加载到内存，页面分批展示；未完成10万条性能验收。
- 捕获到的异常会触发回滚；强制结束进程或持续数据库故障的恢复尚不完整，可能残留数据集写入锁。遇到此情况请先备份并确认无运行中的操作。
- 重复添加同一模型和数据集版本可能改变关联分组，删除关联时可能遗漏早期自动生成的素材关系；暂避免重复添加同一组合。
- 快速连续筛选时旧请求可能覆盖新结果，可重新应用筛选。
- 导出下载仍可能打开新标签页。
- CVAT在线连接、MLflow、分片上传、服务端选择集和全新Linux部署验收不属于本版本已完成范围。

源码不包含真实素材、原始方案文件、运行数据和部署密钥。
