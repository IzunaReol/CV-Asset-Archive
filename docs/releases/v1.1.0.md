# v1.1.0

## 版本概述

增加数据集与不可变版本管理，并完善模型关联、筛选、分页和批量操作。

## 主要变化

- 支持数据集新建、编辑、删除、复制、成员管理和异步导出。
- 支持自定义版本号、版本详情、差异对比和版本恢复。
- 模型可以关联指定数据集版本，素材详情显示所属数据集。
- 数据管理支持分页、高级筛选、跨页选择和批量成员操作。
- 删除数据集时同步清理历史版本与模型关系，保留素材文件。

## 升级说明

1. 备份 MongoDB、MinIO 和部署配置，停止 API、Worker 和前端。
2. 更新代码和依赖，在 `frontend` 执行 `npm ci` 与 `npm run build`。
3. 启动服务，旧集合会迁移为数据集，历史冻结集合迁移为首个版本。
4. 验证登录、素材预览、数据集成员、历史版本和模型关联。

回退时应恢复升级前数据库备份，不能只回退代码。

## 验证情况

- 49 项后端测试、前端类型检查和生产构建通过。
- 临时数据验证复制、分页、发布、移除、版本对比、恢复和删除流程。
- 完成筛选、版本详情、选择工具和夜间模式检查。

## 已知限制

- 上传仍为整文件传输，不支持分片、暂停或断点续传。
- 大批量选择仍依赖前端加载，未完成 10 万条性能验收。
- 强制结束进程后可能残留数据集写入锁。
- 本说明记录 v1.1.0 发布时状态；当前版本能力以最新发布说明为准。
