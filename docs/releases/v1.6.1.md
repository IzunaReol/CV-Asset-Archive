# v1.6.1（2026-10-10）

## 新增

- 增加系统概览，集中展示素材、数据集、关联关系、任务状态、素材构成、素材占比和近期操作。
- 增加全局搜索，可检索素材、模型、数据集、关联关系、任务、用户、角色和系统日志，并按当前账号权限过滤结果。
- 系统管理增加角色管理，支持维护可复用角色、菜单权限和对应操作权限；管理员角色保持只读保护。
- 素材库增加表格列自定义，筛选、排序、每页数量和视图设置按登录用户保存在浏览器中。
- 上传前增加文件内容指纹检查，可识别名称不同但内容相同的中小文件，并在重复文件列表标明重复原因。
- 角色权限保存前增加影响确认，展示将受权限变化影响的用户数量和用户名。
- 系统日志增加登录成功、登录失败、登录限制、退出、权限拦截、服务状态变化和异常任务恢复记录。

## 改动

- 菜单权限与操作权限按菜单分组展示；选择菜单时同步选择该菜单下的操作权限，并统一提供全选和取消全选。
- 无菜单权限或操作权限时，前端隐藏对应页面和操作按钮，后端继续执行独立权限校验。
- 系统日志筛选区统一搜索框、下拉框、开始时间和结束时间样式，并适配白天、夜间和窄屏布局。
- 系统概览的空间统计改为素材占比环形图，展示各类型占比、数量、占用空间和总占用空间。
- 全局下拉框统一圆角、内边距、箭头、悬停、焦点和禁用状态。
- 后台运行期间每分钟检查长时间无更新的任务，将异常任务转为可核对、可重试的失败状态。
- 上传冲突提示同时覆盖同名文件和内容重复文件，分类列表继续支持展开和右侧详情查看。
