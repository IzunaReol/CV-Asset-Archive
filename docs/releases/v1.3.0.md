# v1.3.0

## 主要变化

- 下载中心升级为任务中心，统一中文名称，支持类型、状态、创建时间筛选、失败重试和导出取消。
- 服务启动时恢复异常中断任务，Worker 为运行中任务定期写入心跳。
- 上传弹窗增加暂停和继续，分片上传继续复用未完成会话。
- 默认标签不可删除，自定义标签保持可删除。
- 增加旧集合迁移数据的只读核对脚本。
- 调整任务数量、操作按钮、中文错误提示和登录弹窗文案。

## 验证

- 后端自动化测试、代码检查、前端类型检查和生产构建。
- 隔离 API 端到端流程、真实环境只读接口和主要 UI 页面检查。
- 当前数据迁移核对未发现成员差异。

## 已知限制

- 浏览器安全限制决定刷新页面后仍需重新选择同一文件，系统会凭文件信息复用未完成的分片会话。
- Linux Docker 全新部署、容器备份恢复和镜像扫描实机复核按用户要求跳过，未计入本版本已完成验收。
- CVAT 在线任务同步和 MLflow 集成尚未实现。
