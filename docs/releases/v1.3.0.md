# v1.3.0

## 版本概述

完善任务管理、后台任务稳定性、上传暂停恢复和系统默认标签保护。

## 主要变化

- 下载中心升级为任务中心，支持任务类型、状态和创建时间筛选。
- 支持失败任务合规重试、导出取消、异常中断任务恢复和 Worker 运行时心跳。
- 上传弹窗支持暂停和继续，继续时复用未完成的分片会话。
- 默认标签禁止删除，自定义标签仍可删除。
- 统一任务名称、类型和历史错误中文展示，修正侧栏任务总数及无操作按钮占位。
- 增加旧集合迁移后的数据集、版本和成员只读核对工具。
- 精简登录弹窗文案，并增强 Windows 本机服务启停可靠性。

## 升级说明

升级前备份 MongoDB、MinIO 和部署配置。更新代码及依赖，重新构建前端并重启 API、Worker 和前端。启动时会标记长时间无更新的运行中任务，默认标签会自动补充系统保护标记。升级后应检查任务中心、上传暂停恢复、标签管理和迁移核对报告。

回退时应恢复升级前数据库备份，不能只回退代码。

## 验证情况

- 75 项后端测试、Ruff、前端类型检查和生产构建通过。
- 隔离 API 端到端流程及真实环境 16 个只读接口通过。
- 主要 UI 页面、白天与夜间主题完成检查，浏览器控制台无错误或警告。
- 当前 3 个旧集合完成迁移核对，未发现成员差异。
- GitHub CI 的后端、前端、容器扫描和密钥扫描全部通过。
