# v1.2.1

## 版本概述

改进大文件上传、批量操作、写入恢复、部署维护和持续集成安全检查。

## 主要变化

- 64 MB 及以上文件使用 64 MB 分片，重新选择同一文件可跳过已完成分片。
- 素材库“全部”使用服务端选择集，批量操作不再依赖浏览器保存全部素材 ID。
- 合并多文件上传的初始化和完成请求，提高小文件上传并发。
- 数据集写入锁支持续租，中断的版本恢复可在下一次写入前继续完成。
- 导出接口只接受素材 ID 或服务端选择集。
- 增加 Compose 备份恢复、10 万条性能和 10 GiB 分片上传验证工具。
- CI 增加依赖、容器镜像和仓库密钥扫描。

## 升级说明

升级前备份 MongoDB、MinIO 和部署配置。更新代码与依赖并重新构建前端和容器，然后验证登录、上传、批量选择、数据集写入、导出和回收站。远程浏览器访问 MinIO 时，应正确设置 `MINIO_PUBLIC_ENDPOINT`；使用 HTTPS 时同时启用 `MINIO_PUBLIC_SECURE`。

## 验证情况

- 65 项后端测试、Ruff、前端类型检查和生产构建通过。
- 10 万条隔离元数据常用查询 P95 低于 500 ms。
- 10 GiB 合成内容完成分片、断点识别、合并和大小校验。
- 完成隔离 API 端到端流程和主要 UI 抽查。

## 已知限制

- 前端尚未提供暂停按钮，刷新后需要重新选择同一文件恢复上传。
- Linux Docker 全新部署和备份恢复未完成实机验收。
- 本说明记录 v1.2.1 发布时状态；当前版本能力以最新发布说明为准。
