# 数据集管理

数据集维护当前成员；发布时保存成员名称、类型、大小、校验值、标签和备注的固定快照。恢复历史版本只更新当前成员，不修改历史版本；但确认删除关联素材会移除其历史版本成员记录并重算摘要。

- 图片、视频、压缩文件和其他非模型素材可手动加入数据集；标注不能单独加入。
- 图片加入数据集时会带入有效关联的标注。撤销图片与标注关系或移出图片时，不再由其他集内图片引用的标注会从当前数据集移除；已发布版本不变。
- 新建和修改的状态使用标签管理的状态枚举。
- 新建和编辑数据集必须至少选择一个“所属项目”，可多选，选项来自标签管理的“项目”值。旧数据集可继续查看；未设置项目的旧数据集编辑时需要补齐。
- 复制可只复制名称、备注、状态和所属项目，也可复制当前成员；不复制历史版本和模型关系，不复制对象文件。旧数据集未设置项目时，须先编辑补全才能复制。
- 项目概览按数据集的所属项目列出数据集并汇总当前成员素材构成；跨项目的顶部数据集总数按对象去重，项目内素材数量按数据集成员合计，跨数据集共用素材可能重复计数。模型来源包括自身项目标签及其与项目数据集版本的有效关联。
- 模型只关联已发布的数据集版本。模型与版本成员之间的路径由版本快照推导，不另写模型直连素材关系；解除模型与版本的关联后，推导路径立即失效。
- 删除数据集清除历史版本、成员和对应关系，保留素材对象及独立图片标注关系。
- 删除属于当前数据集或历史版本的素材需要二次确认；删除后会移除这些成员关系，并重新计算受影响版本的成员数、总大小及内容摘要。此操作是历史版本不可变规则的明确例外，从回收站还原素材不会自动恢复原有关联。
- 导出按当前成员创建后台ZIP任务。

API前缀为 /api/v1/datasets，具体请求字段以 /docs 的OpenAPI为准。迁移保留旧集合ID映射，重复执行不会重复创建。

并发写入受到数据集级租约限制，中断恢复会在下一次写入前继续完成。版本详情按页读取，版本对比流式统计全部成员并最多返回 1000 项明细，恢复操作按批次写入并使用一天后自动清理的临时备份。旧集合迁移结果可运行 `python scripts/verify_migrations.py` 只读核对；当前候选版本边界见 [v2.2.0 发布说明](releases/v2.2.0.md)。

## 发布前质量检查

打开发布弹窗时检查当前成员。空数据集、包含失效素材会阻止发布；图片没有关联有效标注、按 SHA-256 与大小确认的重复内容仅作风险提醒，发布人确认后可继续。缺少 SHA-256 的素材不判定为重复。视频和标注文件的内容质量不在本轮检查范围内。

发布请求携带预检令牌，服务端重新计算；成员、素材快照或有效标注关系变化时，拒绝旧令牌并要求刷新。已发布版本保存风险摘要和确认情况，审计日志同步记录。

## 图片用途划分与导出

图片在每个数据集内独立设置用途：训练集 `train`、验证集 `val`、测试集 `test` 或未划分 `unassigned`；旧成员默认未划分。数据管理支持同时选择多个用途筛选，以及跨页多选后的批量修改；重置会清空数据管理的筛选条件。非图片素材没有用途。

“自动分配类型”默认比例 8:1:1，只处理未划分图片。相同 SHA-256 和大小的图片保持同组；已有已划分同内容图片时跟随其用途，若已划分图片彼此冲突则跳过该组。冲突明细显示图片与现有分类，并支持定位到成员。比例分配按图片组尽量接近目标，并非精确配额。比例变化后自动更新预览；预览令牌失效后必须重新预览。

发布版本会将图片用途写入快照；恢复版本同时恢复用途，旧版本中缺少该字段的图片按未划分处理。未划分图片、同内容跨用途和历史一对多标注会进入发布质量提醒，确认后仍允许发布。新建标注关系改为一份标注最多关联一张图片；已有一对多关系保留并提示人工修正。

导出使用当前实时成员，不读取历史版本快照；数据管理支持导出当前所选成员、全部成员，或指定一个或多个图片分类（含未划分）。三种范围均可勾选“导出关联标注”，默认不勾选；勾选后只带入所选图片在数据集内有效关联的标注。“导出当前”和“导出全部”的文件直接放在 ZIP 根目录；“导出指定分类”按分类名称分别建文件夹，图片及其标注放在所属分类文件夹。分类名称含路径禁用字符时，文件夹名中的对应字符替换为下划线；替换后重名的文件夹会追加序号。勾选关联标注后，若标注同时关联了导出范围外或不同分类的图片，分类导出会被拒绝并返回冲突标注 ID；不勾选时不受此冲突影响。导出任务创建时固定成员、分类和标注归属；ZIP 名称为“数据集名称 当前版本 导出类型.zip”，无已发布版本时使用“未发布”。

## 数据集分类规则

创建或编辑数据集时可选择“标准”“自定义”“不分类”。旧数据集默认按标准规则运行。标准规则保留训练、验证、测试和未划分；自定义规则的分类只属于当前数据集，在数据管理的“分类管理”中新增、改名或删除，名称不能重复，删除分类会使其中图片回到未划分。自定义规则的批量分类、筛选、自动比例分配及指定分类导出使用当前分类。比例由用户填写，至少一项大于零。未配置任何自定义分类时不能自动分配。不分类规则隐藏图片分类控件，发布时不提示未划分图片；全部导出的文件直接放在 ZIP 根目录。

编辑时切换分类规则会把当前所有图片分类重置为未划分并清空自定义分类定义，页面在提交前提示确认。已发布版本的快照不会被修改；若恢复的旧版本使用了当前已不存在的分类，对应图片恢复为未划分。自定义分类导出的 ZIP 目录使用创建导出任务时的分类名称；后续改名不会影响已创建任务的目录名。

## 项目概览展示

只使用“所属项目”聚合，不使用数据集算法字段。默认选中所有项目；单选时显示项目名称，清空时不展示项目结果。页面只展示数据集与模型：两者均无数据的项目不显示，对应区域无数据时隐藏。接口暂保留文件统计字段供兼容，页面不展示“其他文件”板块。

模型按项目内关联版本的最新创建时间降序，无关联版本排后。模型可由项目标签或数据集版本关联纳入，两种来源去重；显示备注、关联版本和已配置参数，不展示空备注及 MLflow 占位。项目顶部总数按对象去重，各项目分组并非互斥，不能直接相加替代顶部总数。

## 模型管理

添加关系选择模型时按名称或备注进行服务端搜索，每页加载 50 项；选择模型后带入其备注，模型备注为空时不覆盖已填写内容。已建关系只允许修改关联备注，不允许更换模型或版本。关联备注与模型自身备注是不同字段。

“编辑参数”修改模型文件本身的元数据，所有引用该模型的列表读取同一份值，详见[模型参数](model-parameters.md)。
