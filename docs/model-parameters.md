# 模型参数（v2.0.0）

参数分为指标定义和模型取值。系统管理的“参数管理”维护指标名称、分类与描述；实际值保存在各个模型文件上，不属于某条数据集关联，也不会因同一模型关联多个版本而产生多份值。当前为人工配置的元数据，不执行评估，也未接入 MLflow。

## 默认指标

| 分类 | 指标 |
| --- | --- |
| 图像分类 | Accuracy、Precision、Recall、F1 Score |
| 目标检测 | mAP、IoU、AP |
| 语义分割 | Pixel Accuracy、mIoU、Dice Coefficient |
| 实例分割 | mAP、IoU |
| OCR | CER、WER |
| 姿态和关键点 | PCK、OKS |

共六类 16 项；不同分类的同名指标独立维护。指标说明用于解释含义，不代表系统已计算真实测量值。

## 管理与填写

- “分类编辑”弹窗列出已有分类，支持新增，自定义分类可编辑、删除；仍有指标的分类不能删除，内置分类不可编辑或删除。
- 分类默认展开，点击名称可收起或展开。内置指标不可删除；删除自定义指标会同时移除模型中该指标的值。
- 素材库模型详情的“参数配置”位于“查看模型溯源”上方；数据集模型管理的“编辑参数”位于“编辑备注”左侧，两处修改同一模型的数据。
- 配置表单显示全部指标，空值为“未配置”；模型列表及项目概览仅显示已配置值。保存后同步更新模型修改时间。
- 指标定义管理要求参数管理菜单和 `parameter_manage` 操作权限；模型取值读取和编辑分别要求素材读取及 `asset_edit` 权限，不因可查看数据集而自动获得编辑权。

## 接口注意

`GET /api/v1/assets/{asset_id}/parameters` 返回定义及当前值。`PATCH` 的 `values` 为指标 ID 到值的映射，保存采用**整份替换**而非逐键合并；调用方需提交要保留的全部值，`null` 或未包含的值不保留。只支持未归档模型，非模型或已归档素材返回不存在。具体字段限制以 OpenAPI 为准。

备份 MongoDB 时必须包含指标定义、分类和素材 `metric_values`；仅备份模型文件无法恢复参数配置。
