# 关联关系撤销设计

## 当前行为

关联关系采用软撤销。撤销将状态从 `active` 改为 `revoked`，保留原关系、创建人、创建时间、来源、撤销人、撤销时间和审计记录。有效关系查询与模型图谱不再返回已撤销关系，历史列表仍可筛选和查看。

撤销原因为选填，可以为空；填写后完整保存在关系详情中。数据管理员和管理员可以执行撤销。

## 数据字段

`relations` 使用以下撤销字段：

- `status`：`active` 或 `revoked`
- `revoked_at`
- `revoked_by`
- `revoke_reason`
- `superseded_by`：可选替代关系

重新建立同一三元组时创建新的有效记录，不重新激活旧记录。重复撤销保持幂等。

## 接口与交互

`POST /api/v1/relations/{id}/revoke` 接收可选 `reason` 与 `replacement_relation_id`。撤销成功后前端重新读取关系详情，立即展示“已撤销”和撤销原因。

关系详情使用中文来源：

- `cvat_import`：导入（图片+标注）
- `filename-match`：自动关联
- `web`：手动创建
- `web-model`：模型关联

## 后续保护

冻结数据集成员和已发布模型关系的影响检查仍需完善。若未来增加关系恢复，应创建新的有效关系与审计事件，不删除撤销历史。
